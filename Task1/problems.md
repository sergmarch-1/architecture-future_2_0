Проблемные места текущей архитектуры

1. Устаревший DWH на Microsoft SQL Server 2008: трудно масштабировать, нет поддержки, низкая производительность

2. DWH выполняет функции хранилища + имеет вшитую бизнес-логику для отчетов: повышенный риск при деплое обновлений, сложно адаптировать к новым направлениям бизнеса

3. Монолитные интерфейсы (Power Builder): сложность поддержки и развития

4. Разрозненные технологии (Python, Java, Golang, SQL): сложно поддерживать

5. Нет интерфейса создания отчетов в разрезе бизнес-направлений, с контролем доступа

6. Низкая масштабируемость
